# 01. Архитектура сайта-резюме

Одностраничное резюме на **Astro** на двух языках, собранное на шаблоне
frontend-kit. Статический сайт: при сборке получается два HTML-файла —
`/` (русский) и `/en/` (английский) — и 404.

## Главная идея: содержимое отдельно от вёрстки

```
src/data/resume.ts   ← ВСЁ содержимое: обо мне, навыки, опыт, проекты, пет-проекты
src/i18n/ui.ts       ← подписи интерфейса («Навыки», «Открыть сайт») на двух языках
src/components/*     ← секции, которые только выводят данные
```

Добавить проект или навык — правка одного файла с данными, компоненты не
трогаются. Каждый текст в данных — объект `{ ru, en }`, а функция
`pick(text, locale)` берёт нужный язык.

## Два языка

- Языки перечислены в `LOCALES`, словари подписей — в `ui.ts`. TypeScript
  проверяет, что у английского словаря те же ключи, что у русского, — забытую
  подпись видно ещё до сборки.
- `pages/index.astro` и `pages/en/index.astro` рендерят один и тот же
  компонент `ResumePage` с разным языком.
- В `<head>` для поисковиков: `<link rel="alternate" hreflang="ru|en">` и
  `x-default` — Google понимает, что это одна страница на двух языках, и
  показывает нужную.
- Переключатель языка — **обычные ссылки** на языковые версии, а не кнопки,
  меняющие текст скриптом. Поисковик индексирует то, что лежит по адресу:
  язык, переключённый на лету, он бы не увидел, и английская версия не
  попала бы в поиск.

## Как оживает разметка

Секции помечают элементы атрибутами модулей кита:

```astro
<section data-module="flip-filter"> … </section>
<canvas data-module="aurora"></canvas>
```

`scripts/app.ts` запускает `createApp`: он находит все `[data-module]` и
вызывает модули. Свои модули резюме (`aurora`, `spotlight`, `copy-text`)
подключены лениво — код скачивается, только когда элемент есть на странице.

## Что показывается в «Проектах»

`Projects.astro` показывает только проекты со ссылкой
(`allProjects.filter((p) => p.href)`). Проекты под NDA или без публичной
версии остаются в данных (их можно упомянуть на собеседовании), но на сайт
не попадают. Вкладки-фильтры строятся только по категориям, в которых есть
проекты.

Превью карточки — скриншот (`image`), а если его нет — «обложка» из текста
(`cover`), чтобы карточки не выглядели пустыми.
