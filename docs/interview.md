# Шпаргалка к собеседованию: сайт-резюме

**Почему Astro?**
Контент и SEO: готовый HTML без лишнего JS, интерактив модулями точечно,
встроенная поддержка нескольких языков и статической сборки.

**Как сделаны два языка?**
Тексты — объекты `{ ru, en }` в данных, подписи — словари с одинаковыми ключами
(TypeScript ловит пропуски). Две страницы рендерят один компонент с разным
языком; `hreflang` и `x-default` в `<head>` для поисковиков.

**Как устроен фон первого экрана?**
Свой фрагментный шейдер: fbm-шум (несколько слоёв шума разного масштаба),
сдвигаемый временем; пятна тянутся за курсором с инерцией; цвета из
CSS-переменных; кадры только на экране, плотность ≤ 1,5, без WebGL — CSS-градиент.

**Как сделать подсветку под курсором дёшево?**
JS пишет координаты в CSS-переменные, свечение — `radial-gradient` в CSS.
Один делегированный обработчик на блок, только для мыши.

**Почему часть рабочих проектов не показана?**
Показываются только проекты с публичной ссылкой; проекты под NDA остаются
в данных и в навыках, о них можно рассказать на собеседовании без кода и
названий.

**Что важно при деплое в подпапку?**
Base добавляется к ассетам сборщиком, но не к ссылкам в разметке — все пути
через `withBase`; абсолютные адреса для Open Graph и hreflang — через
`new URL(path, site)`.
