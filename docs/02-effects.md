# 02. Эффекты

## «Северное сияние» на первом экране (`src/modules/aurora`)

Свой WebGL-шейдер без библиотек — около 3 КБ.

**Шум и fbm.** Шум (`noise`) — случайные значения в узлах сетки, плавно
смешанные между ними. Один слой шума — крупные пятна. **fbm** (fractal
Brownian motion) — несколько слоёв шума всё меньшего масштаба и
амплитуды, сложенные вместе: получается «облачная» текстура с деталями
разного размера. Если сдвигать её координаты временем — облака перетекают.

**Курсор с инерцией.** Пятна тянутся за мышью, но не прилипают к ней:
целевая точка (`tx/ty`) меняется сразу, а текущая (`x/y`) каждый кадр
проходит долю расстояния до цели. Резкий рывок мыши превращается в плавное
движение.

**Цвета** — из CSS-переменных `--aurora-1/2/3`: шейдер читает их через
`getComputedStyle`, поэтому палитра настраивается в SCSS, а не в коде
шейдера.

**3D-капля.** Объект справа от имени — не модель, а формула в том же
шейдере. Для каждого пикселя пускается луч вглубь экрана и шагами ищет
поверхность (**ray marching**): функция расстояния `map` отвечает, как далеко
до капли, луч шагает на это расстояние — и так, пока не упрётся. Форма —
шар, по которому бегут волны синусов. Цвет: края ярче центра (эффект
Френеля), блик идёт от курсора, «отражение» — тот же шум fbm в цветах сияния.
Капля поворачивается за курсором, а при прокрутке уплывает вверх, растёт и
тает (`uScroll`). Положение и размер — `blobPlacement()`: на узком экране
капля меньше и в правом верхнем углу.

**Живая сцена.** Чем резвее двигают курсор, тем быстрее и выше волны
(`uEnergy`, `uWave`). Клик или тап — всплеск: фигура вздувается, по ней бежит
рябь, а по фону от точки клика расходится кольцо (`uPulse`, `uClick`).

**Кольцо в контактах.** Тот же модуль с `data-aurora-shape="ring"`: вместо
шара в функции расстояния — тор. Сверху canvas скрыт маской, чтобы сияние
проявлялось плавно.

**Звёзды** — в редких клетках сетки по точке, каждая мерцает в своём ритме.
Только в тёмной теме (`uDark`).

**Бережём батарею:**

- кадры рисуются, только пока canvas на экране;
- плотность пикселей ≤ 1,5 (на телефонах — 1,25);
- лучи считаются только в круге вокруг капли — остальной экран остаётся дешёвым фоном;
- «меньше движения» — один неподвижный кадр;
- нет WebGL — под canvas остаётся CSS-градиент.

## «Уход вглубь» первого экрана (`src/modules/recede`)

При прокрутке текст первого экрана отклоняется назад, уменьшается и тает —
как лист, который кладут на стол. Анимация GSAP привязана к прокрутке
(`ScrollTrigger`, `scrub`): сколько прокрутили — настолько и отклонился.

## «Прожектор» на карточках (`src/modules/spotlight`)

Один обработчик `pointermove` на весь блок (делегирование). Он пишет
координаты курсора внутри карточки в `--spot-x/--spot-y`, а свечение
рисует CSS (`src/styles/_layout.scss`):

```scss
background: radial-gradient(
  420px circle at var(--spot-x, -999px) var(--spot-y, -999px),
  color-mix(in srgb, var(--color-accent) 18%, transparent),
  transparent 60%
);
```

Значение по умолчанию `-999px` уводит пятно за пределы карточки, пока курсор
ещё не наводили.

JS только передаёт два числа — рисование остаётся браузеру. Только для мыши
(`canHover()`): на сенсорном экране наведения нет.

**3D-наклон.** Карточка наклоняется к курсору: углы считает `tiltAngles()`
(широкие карточки наклоняются слабее), поворот делает GSAP — `rotationX /
rotationY` с `transformPerspective`. GSAP же двигает карточки при появлении и
в фильтре проектов, поэтому анимации складываются, а не затирают друг друга.
Курсор ушёл — карточка пружиной возвращается. Выключить:
`data-spotlight-tilt="0"` на блоке; при «меньше движения» наклона нет.

## «Скопировать почту» (`src/modules/copy-text`)

`navigator.clipboard.writeText` работает только на https и localhost. Если
браузер не дал скопировать — открывается почтовая программа (`mailto:`),
чтобы кнопка работала всегда.

## Эффекты из шаблона

Готовые модули кита, подключённые атрибутами:

| Модуль | Где |
| --- | --- |
| `split-text`, `scramble-text` | заголовок первого экрана: буквы появляются по одной, «расшифровка» |
| `reveal` | появление блоков при прокрутке |
| `counter` | числа «набегают» в «Обо мне» |
| `marquee` | бегущая строка технологий |
| `magnetic` | кнопки притягиваются к курсору |
| `flip-filter` | фильтр проектов: карточки перестраиваются анимацией Flip |
| `stack-cards` | пет-проекты складываются стопкой при прокрутке |
| `swiper` | галерея скриншотов в карточке пет-проекта |
| `cursor`, `scroll-progress`, `sticky-header`, `theme-switch` | общие для страницы |

Каждый модуль сам выключается при «меньше движения» и снимает слушатели в
`destroy()`.

## Ошибки

> **Шейдер на полной плотности пикселей.** Размытому фону ретина не нужна, а видеокарта считает в
> 4–9 раз больше. Ограничение 1,5.
>
> **Кадры, пока фон за экраном.** Батарея. Рисовать только при видимости.
>
> **Обработчик `pointermove` на каждой карточке.** Один на блок (делегирование), и только для мыши.
>
> **Ссылка в карточке перекрывает кнопки.** Растянутая ссылка ниже по слою (`z-index`), кнопки и
> галерея — поверх.
